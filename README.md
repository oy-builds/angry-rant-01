# Angry Rant

A make.fun entry for "Angry Judge: The Short Rant Contest": one short,
funny rant about a small everyday annoyance — a broken printer that has
exactly one job and still finds a way to fail at it. The rant is aimed at
the judge's brief: specific, concrete, economical, and genuinely fed up
rather than performed.

`main.ts` (Node 22, standard library only) writes the rant deterministically
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> My printer has one job. ONE. It sits there blinking like it's thinking, then tells me the cyan is low. I print in black. It has never once printed in cyan. It jams on page two, prints a test page nobody asked for, and I've spent more on ink than the machine cost. It's not broken. It's a small grey landlord collecting rent.

Run it with `node main.ts`.
